# 36 — Glomerulus
**Image gate:** PAS renal cortex with a capillary tuft inside Bowman’s space and adjacent tubules.
**Prompt:** Name the structure containing the capillary tuft enclosed by Bowman’s space.
**GTFA:** Glomerulus
**Solution:** Step 1: Find capillary tuft. Step 2: Verify Bowman’s space. Step 3: This defines a glomerulus. **Final answer: Glomerulus.**
**Distractors:** Proximal tubule; distal tubule; collecting duct; arteriole; capillary.
**Failure target:** Using stain color instead of architecture.
